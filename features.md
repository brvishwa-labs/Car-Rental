# SanCars - Application Features

This document outlines the current and planned features for the SanCars Pondicherry Car Rental platform. We will keep adding new features here as the project evolves.

## 1. Customer-Facing Features
*   **Premium Storefront**: A sleek, dark/tropical themed landing page showcasing the car rental service.
*   **Fleet Browsing**: Customers can view available cars with their key specifications (Seats, AC, Transmission, Fuel Type, Price per day).
*   **Car Detail View**: Detailed view for each car showing high-quality images and rental terms (e.g., 300km/day limit, fuel policy).
*   **Booking Inquiry Flow**: A simple form allowing customers to select their dates and submit their contact details for a booking.
*   **KYC Upload**: Secure file upload for mandatory local Indian KYC documents (Aadhar Card & Driving License).

## 2. Admin & Fleet Management Features
*   **Admin Dashboard**: A secure portal for the business owner to manage operations.
*   **Booking Management**: View all incoming booking inquiries, customer contact details, and dates.
*   **Inventory Control**: Add, edit, or remove cars from the website. Update pricing, availability status, and upload new car images.

## 3. Additional/Future Features (Planned)
*   [ ] **Digital Payments**: Integration with Razorpay for customers to pay a security deposit or full advance via UPI/Cards online.
*   [ ] **WhatsApp Notifications**: Automatically send a WhatsApp message to the admin when a new booking is requested, and send booking confirmations to customers.
*   [ ] **Availability Calendar**: A visual calendar view for the admin to see which cars are booked on which dates, preventing double bookings.
*   [ ] **Review System**: Allow past customers to leave ratings and reviews for specific cars.
*   [ ] **Dynamic Pricing**: Ability to set higher prices for weekends or peak tourist seasons.
